# Vincent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build vincent.ar-va.com, a static tool that generates a harmonious light and dark Nextcloud theme, previews it on every kind of screen, and exports the exact settings and Custom CSS.

**Architecture:** Pure TypeScript functions turn a small `Choices` object into two maps of Nextcloud colour variables. `exportCss` writes those maps as CSS, and the same CSS is injected into an isolated preview iframe, so preview and export cannot disagree. The export is proven on a disposable real Nextcloud 35 before the preview screens are built, and those real screens are the reference for the replica.

**Tech Stack:** Astro 7 static site in an npm workspace, Tailwind 4 through `shared/`, plain browser TypeScript, Node's test runner, headless Chrome over CDP, Colima + Docker for the real Nextcloud.

**Spec:** `docs/superpowers/specs/2026-11-23-vincent-design.md`

## Global Constraints

- Every theme is a light and dark pair. The export contains colours only.
- Text pairs at least 4.5:1, controls and icons at least 3.2:1, in both modes. Fix contrast by changing lightness only.
- Work in OKLCH, clamp to sRGB by lowering chroma, output hex.
- Never change `light-highcontrast` or `dark-highcontrast`.
- Login preview: no `<form>`, no password input, inert fields, permanent "Preview" label, `noindex`, no Nextcloud name or logo in the mock.
- Copy no code, icons or images from Nextcloud. Icons: Material Design Icons (Apache-2.0). The site says it isn't affiliated with Nextcloud.
- No UI framework and no colour library. `vincent/src/lib/` has no browser APIs and imports siblings with a `.ts` extension, so Node's tests run it directly.
- No server code: static assets only, as in `brand/wrangler.jsonc`. Images never leave the browser.
- Reuse `shared/` (Layout, Header, Footer, Disclosure, Notice, `.ctl`, `.btn-primary`). Build a UI pattern once.
- Git: author `ARVA <github@ar-va.com>`, **no Co-Authored-By trailer, never push**, no surname anywhere. Stage named files only; leave `.claude/skills/landing-page-design/SKILL.md` alone.
- Update the git-ignored `CLAUDE.md` when the project's structure or decisions change. Dates as YYYY-MM-DD.

## Review Focus

- Extreme primaries (pure white, black, yellow, grey): the theme still passes every contrast pair and doesn't turn muddy. Test: Task 2.
- A damaged, old or hand-edited page address: the default theme loads, no crash. Test: Task 2.
- The exported CSS loads before or after Nextcloud's stylesheets: the result is identical. Test: Task 3.
- A huge, transparent, corrupt or non-image upload: a clear message or sensible colours, no frozen tab. Test: Task 5.
- A wheel drag leaving the circle, and copying where the clipboard is blocked: the handle clamps to the edge, the code gets selected for manual copy. Tests: Tasks 5 and 9.

### Task 2: Harmonies and theme generation

**Files:**
- Create: `vincent/src/lib/harmony.ts`, `vincent/src/lib/theme.ts`, `vincent/src/lib/nextcloud-vars.ts`
- Test: `vincent/tests/theme.test.js`

**Interfaces:**
- Consumes: everything from `color.ts`.
- Produces:
  - `type Harmony = 'complementary' | 'split' | 'analogous' | 'triadic' | 'tetradic' | 'monochromatic' | 'custom'`
  - `harmonyColors(primary: Oklch, harmony: Harmony, custom: string[]): string[]` (hex accents, excluding primary)
  - `NEXTCLOUD_COLOR_VARS: readonly string[]`
  - `interface Choices { primary: string; harmony: Harmony; custom: string[]; style: 'muted' | 'balanced' | 'vivid'; tint: number; page: 'neutral' | 'primary' | 'secondary' }`
  - `DEFAULT_CHOICES: Choices` (primary `#624db4`, triadic, balanced, tint `0.35`, neutral)
  - `interface Theme { light: Record<string, string>; dark: Record<string, string>; accents: string[]; notes: { role: string; mode: 'light' | 'dark'; from: string; to: string }[] }`
  - `generateTheme(choices: Choices): Theme`
  - `CONTRAST_PAIRS: { fg: string; bg: string; min: number; label: string }[]`
  - `encodeChoices(c: Choices): string`, `decodeChoices(text: string): Choices` (never throws, invalid fields fall back to the default)

Harmony offsets in degrees: complementary `[180]`, split `[150, 210]`, analogous `[30, -30]`, triadic `[120, 240]`, tetradic `[90, 180, 270]`. Monochromatic keeps the hue and varies lightness and chroma. Custom uses `custom`. Role mapping and status rules are in the spec's table. A fourth colour feeds only the Assistant gradient.

- [ ] **Step 1: Generate `nextcloud-vars.ts`** from the names in `https://raw.githubusercontent.com/nextcloud/server/master/apps/theming/css/default.css` matching `^\s*--(color|gradient|primary-invert|background-invert|background-image-invert|image-background)`. Expected: 76 names, names only.
