# Wishlist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every collector's shelf gets a wishlist (Discogs wantlist or a custom list, switchable) that logged-in visitors can reserve, hidden from the owner, with Telegram reminders and "I gave it".

**Architecture:** Pure rules in `shared/lib/wishlist.ts` (tested with Node). D1 tables added to the shared lazy schema; wishlist database code in `music/src/lib/wishes.ts`. Discogs wants ride the existing browser sync; link lookups use the existing Apple (browser) and YouTube Music (server) code. A new page `music/src/pages/[user]/wishlist.astro` with server-rendered forms (303 back), a daily cron and the existing Telegram webhook for reminders.

**Tech Stack:** Astro 7 on Cloudflare Workers, D1, Tailwind 4, Node test runner.

**Spec:** `docs/superpowers/specs/2026-11-24-wishlist-design.md`

## Global Constraints

- The owner's pages never contain reservation data (absent from the HTML, not hidden); logged-out visitors get no reserved state either.
- Copy names the owner ("Artur"), never a pronoun. Dates shown with three-letter months ("Dec 25").
- Server never calls Discogs; Apple's iTunes API only from the browser.
- Cover hosts: `i.discogs.com`, `is*-ssl.mzstatic.com`, `i.scdn.co`, `lh3.googleusercontent.com`, `i.ytimg.com`; https only.
- Limits: 200 custom items per owner; 20 active reservations per person; note ≤ `NOTE_MAX` (280); ≤ 300 tracks; text caps 300.
- Reminders: 3 days before `give_on`, the day after it; without a date 14 days after reserving, then every 30 days; at most one per reservation per day.
- Commits as ARVA, no Co-Authored-By trailer; never push.
- Reuse `Cover`, `Listen`, `Disclosure`, `Notice`, `Breadcrumbs`, `LoginButton`, `.btn-primary`, `.ctl`.

## Review Focus

- A reservation for an item that is no longer shown (switched list, owned, gifted) is refused: test in Task 2 (`canReserve`).
- Two people reserving at once: the second gets "Reserved" (primary key); checked on preview in Task 5.
- A Telegram tap from someone other than the reserver does nothing: preview check in Task 6.
- A tampered lookup / form post with a foreign cover host or script text: `toWish` test in Task 1.
- Discogs wants sync that changes nothing writes nothing: `saveWants` compares rows (Task 3), preview check.

### Task 1: Pure rules (`shared/lib/wishlist.ts`)

**Files:** Create `shared/lib/wishlist.ts`, `shared/tests/wishlist.test.js`; modify `shared/lib/lib.ts` (`safeCoverUrl`, `signablePath`), `shared/tests/lib.test.js`.

**Produces:**
- `parseStreamingLink(url: string): { service: 'apple'|'spotify'|'youtube'; id: string; country?: string } | null` — Apple `music.apple.com/<cc>/album/(<slug>/)?<id>`; Spotify `open.spotify.com/(intl-xx/)?album/<id>`; YouTube `music.youtube.com/browse/MPREb_…` (id as is) and `(music.|www.)?youtube.com/playlist?list=OLAK5uy_…` (id = `VL<list>`). Tracks, artists, other playlists, other hosts → null.
- `interface Wish { artist: string; title: string; year: number | null; cover: string | null; tracklist: string; links: { spotify: string; apple: string; youtube: string }; note: string | null }`
- `toWish(input: any): Wish | { error: string }` — trims/caps text (300), year 1900..current+1 else null, `safeCoverUrl`, links through `safeStreamingUrl` (empty when bad), tracklist via `textToTracklist` → max 300 → `tracklistToText`, `cleanNote`; error "Add the artist and the album." when either is empty.
- `ownedKey(artist: string, title: string) => artistKey(artist) + '|' + normalizeName(title)`; `isOwned(item: {masterId?: number; releaseId?: number; artist: string; title: string}, shelf: {masters: Set<number>; releases: Set<number>; names: Set<string>}): boolean` — master (non-zero), else release, else names.
- `type ReserveState = 'none'|'login'|'free'|'mine'|'taken'`; `reserveState(reservedBy: number | null, viewerId: number | null, ownerId: number): ReserveState` — owner → none; no viewer → login; null → free; viewer → mine; else taken.
- `reminderDue(r: { created_at: number; give_on: string | null; reminded_at: number | null }, today: string /* YYYY-MM-DD UTC */): 'before' | 'after' | 'nudge' | null` — with give_on: `before` on give_on−3 days, `after` on give_on+1 day; without: `nudge` when ≥ 14 days since created and (never reminded or ≥ 30 days since reminded_at); never twice on the same UTC day as `reminded_at`.
- `safeGiveOn(value, today): string | null` — YYYY-MM-DD, today ≤ d ≤ today+365.

### Task 2: Tables and database code (`music/src/lib/wishes.ts`)

**Files:** Modify `shared/lib/store.ts` (SCHEMA, COLUMNS, `removeShelf`); create `music/src/lib/wishes.ts`.

**Schema** (SCHEMA): `wishes(id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER NOT NULL, data TEXT NOT NULL, created_at INTEGER NOT NULL)` + index on user_id; `wants(user_id INTEGER NOT NULL, release_id INTEGER NOT NULL, data TEXT NOT NULL, PRIMARY KEY (user_id, release_id))`; `reservations(owner_id INTEGER NOT NULL, item TEXT NOT NULL, user_id INTEGER NOT NULL, created_at INTEGER NOT NULL, give_on TEXT, reminded_at INTEGER, gifted_at INTEGER, PRIMARY KEY (owner_id, item))` + index on user_id. `users.wishlist_source TEXT` in the definition and COLUMNS.
`removeShelf` also deletes the user's wants, wishes and reservations as owner.

**Produces (wishes.ts):**
- `type WishItem = { key: string /* 'd:<release>' | 'c:<id>' */; artist; title; year; cover; tracklist: Track[]; links; note: string | null; masterId?; releaseId? ; vinyl: null; instanceId: number }` (instanceId = release id or wish id, for `Cover`).
- `wishlistData(name: string, viewer: User | null)` → `{ owner: User | null; source: 'discogs'|'custom'; items: (WishItem & { state: ReserveState; giveOn: string | null })[]; customCount; wantsCount }` in one batch: owner, wants, wishes, shelf records (masters/releases/names), releases + matches for wants, reservations of this owner **only when `viewer && viewer.id !== owner.id`**. Hides owned items and items with `gifted_at`. Newest first.
- `wishCount(ownerId)` not needed: the shelf page computes the count from `wishlistData`? No — add `shownWishCount` as one extra query in `shelfData`'s batch (count of the shown list, minus gifted; owned not subtracted, *shortcut:* count includes owned items until the page is opened).
- `setWishlistSource(user, source)`; `addWish(user, wish: Wish)` (refuses past 200 → false); `updateWish(user, id, wish)`; `removeWish(user, id, origin)` (deletes the reservation and notifies, below).
- `reserve(owner: User, item: string, user: User, giveOn: string | null): 'ok'|'taken'|'limit'|'gone'`, `unreserve(owner, item, user)`, `setGiveOn(owner, item, user, giveOn)`, `markGifted(ownerId, item, userId, origin): Promise<boolean>` (sets `gifted_at`, notifies owner: "<b>Maya</b> gave you <b>Blackstar</b> 🎁" + Discogs line for `d:` items; returns false if not that user's active reservation).
- `itemOnShownList(owner, item): Promise<WishItem | null>` (used by reserve; checks source, existence, not owned, not gifted).
- `dropGone(ownerId, keys: string[], ownedKeys: Set<string>, origin)`: for active (not gifted) reservations among `keys`, delete them and notify the reserver: owned → "Artur now has <b>Blackstar</b> on the shelf, so your reservation is closed. Thank you!" else "Artur took <b>Blackstar</b> off the wishlist, so your reservation is gone. If you already bought it, you could still give it." (owner name escaped; item title escaped.)
- `myReservations(user)` → active reservations with owner name/slug and item artist/title/cover (one batch: reservations + wishes + wants by key).
- `dueReminders(today)` → active reservations joined to item and owner, filtered by `reminderDue`; `markReminded(owner_id, item, at)`.
